# The Digital Detective

## About this project
This is my Diwali independent learning assignment exploring computer systems, command-line operations, operating systems, programming execution, data encoding, version control, and computer networks.

## My Learning
During this assignment, I have deepened my practical understanding of computer fundamentals:
1. **The IPOS Cycle and Operating Systems:** How user input is transformed into machine instructions by the CPU and operating system kernel, and how processes, memory, and permissions are managed safely.
2. **Command-Line Fluency:** Navigating directories, using flags and Unix pipelines to filter data streams, and managing files using terminal redirection.
3. **Data Representation & Execution:** How numbers and text are represented at the hardware level in binary, hexadecimal, and ASCII/UTF-8, and how compilers and interpreters execute programs.

## Running the number converter
1. Open Terminal and go to the mission folder:
   ```bash
   cd mission-05-numbers-data
   ```
2. Run the script:
   ```bash
   python3 number_converter.py
   ```
3. Enter a positive decimal number when prompted (e.g., `42`).
4. The program prints the corresponding binary (base 2) and hexadecimal (base 16) representations.
