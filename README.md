## Topics Explored
- **Computer Fundamentals & IPOS:** Tracing the Input-Processing-Output-Storage model in everyday desktop activities and analyzing embedded systems (ATMs, smart traffic controllers, appliances).
- **Terminal & Command-Line Operations:** Directory traversal (`pwd`, `cd`), directory listing (`ls -lah`), file manipulation (`touch`, `cp`, `mv`, `cat`), overwrite vs. append redirection (`>` vs `>>`), Unix pipelines (`|`), and package managers (Homebrew).
- **Operating Systems, Processes & Permissions:** Inspecting system specs, processes and PIDs, absolute vs. relative paths, Unix permission bits (`rwx`), and fundamental OS responsibilities.
- **Program Execution:** Comparing compiled vs. interpreted programming languages and executing Python scripts from the shell.
- **Numbers & Data Representation:** Manual step-by-step conversions between decimal (base 10), binary (base 2), and hexadecimal (base 16); verifying conversions in Python; building an interactive CLI number converter; and understanding character encodings (ASCII vs. UTF-8).
- **Git & GitHub Workflows:** Tracking status, staging, atomic commits, isolated feature branching (`update-about`), opening and merging GitHub Pull Requests (#1), and mastering essential Git commands.
- **Computer Networks:** Exploring LAN, MAN, WAN, routers, packet switching, and client-server architecture; conducting network latency and DNS lookups with `ping` and `nslookup`; and mapping the 7-step lifecycle of loading a web page.

## Running the Number Converter
A Python number converter was developed in Mission 5 to convert positive decimal integers into binary and hexadecimal representations.

To run the program:
1. Open Terminal and navigate to the Mission 5 folder:
   ```bash
   cd mission-05-numbers-data
   ```
2. Execute the script:
   ```bash
   python3 number_converter.py
   ```
3. Enter any positive decimal integer when prompted (e.g. `42` or `255`).
4. The program displays the formatted decimal, binary (with `0b` prefix and raw bits), and hexadecimal (with `0x` prefix and raw hex digits) results.
