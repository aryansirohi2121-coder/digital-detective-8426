## 4. My understanding
- **What is a Git repository?**
  A repository (repo) is a managed storage structure that tracks the complete lifecycle of project files over time, recording every modification as an immutable commit history so changes can be tracked, reviewed, or restored.
- **Why is the structure organised by mission?**
  Organising by mission keeps work modular, predictable, and easy to audit. Each mission tackles an independent topic (hardware, terminal, OS, programming, encoding, version control, networking), allowing dedicated documentation, clear commit checkpoints, and isolated verification.
